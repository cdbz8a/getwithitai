What “Improve” actually does

It runs the same checklist as the scorer. If a role, format, limit, or example is missing, it adds a generic line. It does not know your pastry special. Read every added line. Delete anything that isn’t true.

Does this call an AI API?

It is JavaScript in your browser, same as the scorer. GitHub Pages has no prompt-server attached.

Why is the improved prompt longer?

Missing structure got added. Length is not the goal. A 40-word job with a role and a ban can outscore a rambling page.

Can I still use the generator?

Generator builds from a description. Optimizer repairs a prompt you already have. Prompt generator · Scorer.
