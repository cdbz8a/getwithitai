How this generator works

Does my text leave the browser?

The prompt is built here, in JavaScript. If someone runs the optional local Grok setup (tools/prompt-server.py and an XAI_API_KEY), then the description is sent to xAI’s API to write the prompt. The public GitHub Pages site stays on-page.

Which models?

The output is a prompt you paste into ChatGPT, Claude, Gemini, Grok, Copilot, Perplexity, DeepSeek, or Llama. We format the wrapper to match the one you pick.

Is the score “AI”?

The scorer is a fixed checklist (role, format, limits, and so on). Same prompt, same number, every time.
